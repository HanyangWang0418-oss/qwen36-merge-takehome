# qwen36-35b-e2_terminal_agent

LoRA adapter (rank 32, all linear projections incl. MoE expert matrices) on
[Qwen/Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B) revision `995ad96eacd98c81ed38be0c5b274b04031597b0`,
trained on Tinker for the take-home "multi-expert training and merging" study.
Expert role: **terminal / research-execution agent** (target benchmark: Terminal-Bench 2.0, ASI-Bench).

## Training
| item | value |
|---|---|
| method | LoRA (Tinker managed), bf16 |
| rank / alpha | 32 / 32 (scaling 1.0; exported adapter_config lora_alpha=32) |
| target modules | all linear projections: self_attn q/k/v/o, Gated-DeltaNet in_proj_q/k/v/z + out_proj, shared_expert gate/up/down, routed experts w1/w2/w3 (fused 3D, one side shared across 256 experts), unembed (lm_head); router not adapted |
| data | Terminal / tool-use / research-execution trajectories (Terminal-Bench 1.x minus 2.0 overlap, AgentTuning, synthetic shell + science tasks) |
| examples / loss tokens | 2718 / 9,240,494 |
| steps / batch / LR / schedule | 170 / 32 / 0.0001 / cosine, 20 warmup |
| context length | 32768 |
| seed | 42 |
| checkpoint selection | lowest dev loss on a held-out split of the training mixture (0.2031 at step 170); benchmark data never used |
| Tinker source | `tinker://423b1516-45ff-5480-b185-cc72ee3a4fa1:train:0/sampler_weights/e2_terminal_agent_r32_s42_20261016_step00170` |

## How to load
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.6-35B-A3B", revision="995ad96eacd98c81ed38be0c5b274b04031597b0", torch_dtype="bfloat16", device_map="auto")
model = PeftModel.from_pretrained(base, "ssyhw7/qwen36-35b-e2_terminal_agent")
```
vLLM: `vllm serve Qwen/Qwen3.6-35B-A3B --enable-lora --lora-modules e2_terminal_agent=<path to this adapter>`
